# Cricket Crown: Dictionary Showdown

A small, immediately playable 3D browser battle-arena prototype. The boss is a fictional fantasy character, the **Dictionary Striker**.

## Play

Open `index.html` in a modern browser with internet access (Three.js loads from jsDelivr), or enable GitHub Pages for this repository and open its site URL.

- **WASD** move · **Mouse** aim · **Click** fire · **E** open nearby chest / pick up weapon · **Shift** sprint
- Find glowing weapon drops and explore the large arena.
- Every treasure chest has a **50% chance** of awarding a Pirate Token; otherwise it grants a weapon.
- Defeat the Dictionary Striker, who chases you, swings a cricket bat, and throws flying dictionaries.

No build step or install is required. This is a browser-game prototype; the page needs internet access to load the Three.js module.
